# Data Documentation Index

Thư mục này chứa các tài liệu đặc tả quan trọng về nguồn dữ liệu (cảm biến OT, biên bản bảo trì PM Cards) và phương pháp sinh dữ liệu mẫu cho hệ thống huấn luyện mô hình.

- [GENERATION-GUIDE.md](GENERATION-GUIDE.md) - Hướng dẫn thuật toán toán học để sinh dữ liệu giả lập (mock data) cho từng pha hoạt động của các cảm biến robot.
- [OT-SENSOR-DATA.md](OT-SENSOR-DATA.md) - Đặc tả cấu trúc bảng dữ liệu chuỗi thời gian liên tục (thô) từ các cảm biến robot.
- [PM-CARD-DATA.md](PM-CARD-DATA.md) - Phân tích cấu trúc, độ nhiễu và chất lượng của Biên bản bảo trì (PM Cards) được dùng để làm dữ liệu gán nhãn thực tế.
